# Adaptive Auto Connector v0.1.15-test7

Locally validated, unpublished test build. Prepared September 12, 2026; runtime checks completed September 11. This is not a stable-release announcement.

## Changes

- Unserved CPU/GPU speed inputs with numeric `required=0` can now receive legal recommendations. Other zero-required resources remain excluded; no artificial material requirement or capacity ratio is introduced.
- Smart Manager ranking uses independently checked raw binding demand and a conservative `max(live demand, raw binding demand)` baseline plus the proposed consumer's projected demand. The manager contribution is bounded to -4 through +4 and falls back to zero when validation fails.
- Explicit Adaptive Smart Manager detection attributes both Thread and GPU capabilities to ASM. Legacy detection remains available but was not newly runtime-tested.
- Manager diagnostics distinguish synthetic diagnostic projections from conditionally enabled candidate scoring.
- Existing player preferences, live legality checks, guarded Accept, exact-edge Undo and topology ownership remain in place. No new polling timer or automatic connection path was added.

## Verification

All 58 automated checks passed in Godot 4.6.1. Three planned in-game checks passed with the original ASM test20 package in Demand mode: Thread scoring with count/s, Analyzer Accept/Undo, and positive-demand GPU scoring with count. Both positive-demand manager candidates applied +4. Raw mirrors agreed; all observed graph integrity error counts were zero, and each session ended with the original 472 edges restored.

See [the runtime report](../../tests/RUNTIME_TEST7.md) and [test instructions](../../tests/README.md). These results establish the exercised behavior, not throughput improvement or universal compatibility. GPU Accept/Undo, other manager modes/bases and legacy standalone managers were not newly exercised. The pre-existing base-game `ad_prompt.gd` / undeclared `Ads` error remains outside AAC.
